# KGTF ENGINE

A modular, browser-based 3D game engine.

## Technology
- JavaScript ES Modules
- Three.js
- WebGL 2
- glTF / GLB

## Architecture

- core: Engine lifecycle and core systems
- rendering: Rendering pipeline
- scene: Scene and object management
- editor: Editor interface and tools
- environment: Sky, lighting and atmosphere
- assets: Asset loading and management
- physics: Physics and collision
- animation: Animation systems
- audio: Audio systems
- ai: Artificial intelligence
- utils: Shared utilities

## Development Principles
- Modular architecture
- Mobile-first design
- Stability before features
- Incremental implementation
